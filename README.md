# HotPipe

Часто использую SSH туннели. Вы тоже?

С SSH туннелями есть проблема: они периодически и внезапно отваливаются в самый неподходящий момент, нужно их снова поднимать. 

Да, можно сделать скрипт для запуска туннелей, но лезть его запускать мне тоже не хочется. Хочется чтобы всё само работало без моего участия.

Сделал утилиту 👉 которая следит за туннелями, освобождая моё время для более важных дел.

Состоит из двух частей:

1. Сервер на Go, крутится в WSL, поднимает туннели, мониторит их статус, переподнимает если туннель сдох.

2. GUI (Tauri) на десктопе Windows — для проверки состояния, удобного управления, редактирования туннелей.


<img src="https://raw.githubusercontent.com/Nex-Otaku/hotpipe/master/docs/images/window.png" width="936" height="686">

```
┌─ Windows ──────────────────────────┐      ┌─ WSL ──────────────────────────────────┐
│ hotpipe-gui.exe        окно        │ HTTP │ hotpipe-server          демон на Go    │
│   ↕ 127.0.0.1:46310 ───────────────┼──────┼─► API, ~/.config/hotpipe/tunnels.json  │
│ hotpipe-gui.exe --keeper  сторож   │      │   ├─ ssh -N -L 5001:…  ─────────────────┼─► сервер
│   держит wsl.exe ──────────────────┼──────┼─► └─ ssh -N -L …                        │
│ HKCU\…\Run → сторож при входе      │      │      поднимает упавший ssh заново      │
└────────────────────────────────────┘      └────────────────────────────────────────┘
```
