# Диагностика

| Видно | Что делать |
|---|---|
| «Сервер не отвечает», сторож работает | WSL стартует до 10–20 с после перезагрузки. Дольше — журнал «Окно и сторож»: чем кончается `wsl.exe` |
| сторож пишет «сервер завершился: exit code: 1» сразу | `~/.local/bin/hotpipe-server` нет или испорчен `tunnels.json` — журнал сервера скажет |
| «сервер не принял ключ» | `ssh-copy-id`; ключ с парольной фразой демону не годится |
| «локальный порт 5001 занят: ssh (pid …)» | туннель, поднятый руками, — `kill <pid>`, HotPipe займёт порт сам |
| «ключ сервера не совпал» | сервер переустанавливали? `ssh-keygen -R '[хост]:порт'` |
| версии окна и сервера расходятся | одну из частей не пересобрали: `build/build.sh && build/install.sh` или `build\build-gui.ps1` |
