# Окно

- **Переключатель «Сервер HotPipe»** — включает и выключает сервер вместе со
  сторожем. Выключение запоминается: выключенный сервер не поднимет ни сторож,
  ни открытие окна, ни вход в Windows (до включения переключателем обратно).
  Подписи у переключателя нет, пока всё в порядке: работает ли сервер, видно
  по его цвету; «Не отвечает» появляется, только если включённый сервер молчит.
- **Туннели** — у каждого свой переключатель (запоминается сервером и переживает
  перезагрузку), состояние, число перезапусков, кнопки «изменить» и «удалить»
  (в два щелчка). Перезапустить туннель руками — выключить и включить. При сбое — объяснение словами и вывод
  самого ssh.
- **Добавить туннель** — можно просто вставить привычную команду `ssh … -L …`,
  поля заполнятся сами.
- **Внизу окна** — версии окна и сервера (полные сведения о сборке — во
  всплывающей подсказке) и ссылки:
  - **Журналы** — сервера (из WSL) и окна со сторожем;
  - **Настройки** — галочка «Запускать при входе в Windows» (действует сразу),
    как часто проверять связь (`ServerAliveInterval`, `ServerAliveCountMax`),
    дистрибутив WSL, порт API, путь к серверу; кнопка перезапуска сервера.

Состояния туннеля:

| | |
|---|---|
| **работает** | порт слушается самим ssh — туннель есть |
| **подключаюсь…** | ssh запущен, порта ещё нет |
| **сбой, повтор через N** | ssh завершился; причина — под строкой туннеля |
| **выключен** | выключен переключателем |
